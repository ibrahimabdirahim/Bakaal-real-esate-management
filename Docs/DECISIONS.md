# Bakaal Real Estate Management System — Decision Register

**Created:** 2026-10-20 (Phase 1, Step 3a)
**Purpose:** One place to record what has been decided, at what status, and what still needs a decision.

## Status labels

| Label | Meaning |
|---|---|
| **Approved** | Explicitly selected or authorised by the project owner. |
| **Proposed** | Recommended or chosen in discussion, but not yet confirmed. |
| **Deferred** | Deliberately postponed to a later phase. |
| **Unresolved** | Needs a future decision. |
| **Implemented** | Built in the project **and** verified. |

A rule that has only been discussed or proposed is never marked Implemented. A status changes only on the project owner's explicit instruction.

**Sources:** the three original documents in `Docs/` (unchanged), the requirements-clarification conversation of 2026-10-20, and the project files as inspected on 2026-10-20.
